# OpenLXSSH 使用说明（开发中）

本说明对应正在开发的V1.0，不代表已发布或产品验收通过。正式目标为Apple Silicon/macOS26；当前开发机macOS15的HostProbe只是隔离测试版本，不能代替正式安装包。已授权本机隔离环境中已有真实SSH/SFTP及部分原生交互证据，但正式macOS26运行、24小时、签名发布和双机使用仍未完成；实际覆盖见 `docs/acceptance.md`。

## 主机与会话

在主机列表选择“添加主机”，填写名称、直接可达的地址、端口、用户名和认证方式。文件夹只有一层；收藏是已有主机入口，复制主机使用新ID但保留共享凭据/密钥关联。删除文件夹只解组，不删除主机。

双击主机优先切到最近活动的有效标签；显式“新建独立会话”创建另一连接。切换标签不重建终端。断开后只保留当前标签的内存历史，不自动重连；“手动重连”重新核对当前主机配置并开始新的认证代次。关闭标签直接取消该连接，不弹普通确认。重开主窗口或重启App不会恢复连接/标签/历史，也不会自动触发MFA。

首次直连展示主机、端口、算法与完整SHA256指纹。预扫不是身份认证，请通过服务器控制台/管理员等独立渠道核实后再接受。已知密钥变化会阻止连接；“可信主机”管理只能在人工核实后精确替换该端点/算法的新公钥，不应为了连通随意覆盖。App不读取或修改`~/.ssh/config`或系统known_hosts。

## 密钥与凭据

“密钥与凭据”支持导入标准OpenSSH格式Ed25519/RSA私钥、生成Ed25519、公钥显示/复制。导入创建App管理副本，不更改/删除源文件。复制公钥不等于私钥导出，App不自动安装服务器authorized_keys。

密码/私钥口令只有显式选择记住才保存到本机Keychain，禁用同步；OTP不保存。Keychain不可用或挑战无法可靠分类时使用人工输入，不猜测提示类型。当前目标macOS26的OpenSSH自动密码白名单未完成时会保守人工回退；即使保存了口令，也不会把它自动投给未知MFA。

认证框区分本次秘密回答、确认和通知。普通终端中的`Password:`、sudo或嵌套SSH提示不触发App秘密发送。关闭/取消认证使旧回答失效，不能无限自动重试。

共享资源仍被其他主机引用时不能直接删除。忘记当前主机密码或私钥口令只先解除关联，无共享引用时才精确清理。若配置已提交但后续清理失败，界面提示待清理，不应重复创建；管理窗口提供精确重试。恢复记录为prepared时并不证明外部资源已创建，可人工核对后仅丢弃记录，不会扫描删除未知文件。

## 终端与手动嵌套SSH

复制、粘贴和当前标签历史搜索位于终端工具栏。多行粘贴直接发送，不额外确认；Bracketed Paste不能保证远端程序不会执行输入。历史默认10000行、当前有效上限50000；字体字号6～72，设置保存后应用到已有终端。默认配色跟随实际深浅外观，选择预设或修改颜色后保持显式自定义颜色。

需要第二跳时，先登录直接可达跳板主机，再在远程终端手动运行ssh。内层密码、OTP、审批及主机身份由远端ssh/用户处理。App只管理最外层，不提供自动ProxyJump、经跳板的图形SFTP或端口转发。

## SFTP与传输

右侧文件面板默认隐藏；选主机后打开，显式“连接 SFTP”才按当前配置独立认证。仅直接可达服务器，SSH和SFTP可分别认证、重复MFA，不根据终端当前目录猜内网目标。已在授权隔离服务器上验证适用认证、真实2GiB/1000文件与异常，以及部分App原生文件操作；这些host15分项不代表任意服务器、正式目标系统或人工Finder已经验收。

上传选择一个或多个文件/目录，下载选择列表中的文件/目录与本地目标目录；也可将Finder文件URL拖入列表。任务有独立入口，隐藏面板、切换或关闭SSH标签不取消任务。冲突可覆盖、跳过、单项改名，覆盖/跳过可限同主机本批次；风险另行逐次核对，覆盖决定不自动接受风险。重试从零创建新任务，不自动重连或续传。移除已完成记录不删除文件或残留，先保存精确残留路径。

关闭主窗口/退出遇活动任务，选择继续会保留窗口并取消退出，选择取消并关闭则等待任务与连接真正清理；无法清理的自有临时路径须先记录确认，不自动扫描或删除。没有传输时关闭直接取消连接/认证/目录操作。本地自动回归、竞态审查和host15真实上传期间关窗/退出分项已有证据；正式macOS26、多任务完整矩阵及人工交互仍待验。

已实现的文件核心使用有界流式传输和唯一临时文件，不先删除旧目标。覆盖不是文件树整体事务；服务器能力不足、符号链接、竞争变化或取消会逐项报告失败/跳过。远端路径检查和最终覆盖存在无法完全原子化的风险，需在产品中明确确认；不能保证能力时拒绝提交，不能用忽略校验换取成功。源文件传输中变化会尽可能检测并保留原目标，但不是原子源快照。

## 权限异常

App专属数据、信任、会话、恢复和私钥路径除了POSIX权限，还拒绝扩展文件系统ACL。即使文件显示0600/目录0700，ACL仍可能授权其他用户访问。ACL查询失败也拒绝操作；包括仅deny或显式空ACL在内均保守拒绝。App不会静默清除ACL、修服务器配置、关闭系统保护或改用不安全位置。请自行核实专属目录或选择安全导入副本，单纯chmod不等于移除ACL。

## 安装与卸载边界

已有本地内部候选用于构建与封装核对，**尚无完成正式发布验收的 Release**。候选打包器默认未签名内部用途，可显式使用既有Development身份离线签名；脚本成功、strict验证或ZIP生成不意味着Gatekeeper、真实登录或双机安装通过。每个候选只覆盖manifest列出的具体源码，旧候选不代表后续修复。签名、公证状态以该产物manifest和验收记录为准，不应移除隔离标记或关闭Gatekeeper解决问题。

后续正式安装应通过已签名/按授权公证的OpenLXSSH.app。卸载App不应假设同时删除Keychain或Application Support数据；需要清理凭据时先通过App精确解除引用/清理，保留失败项，不能宽泛删除用户Keychain或SSH目录。
