# OpenLXSSH 用户指南

OpenLXSSH 面向 **Apple Silicon（M 系列芯片）Mac**，要求 **macOS 26 或更新版本**。应用提供原生 SSH 终端、终端分屏、多窗口工作区与双栏 SFTP 文件传输，无需云账号，所有配置与凭据仅保存在本机。

> 架构与技术说明见 [架构说明](architecture.md)；产品范围见 [需求说明](requirements.md)。

## 安装、升级与卸载

- **安装**：打开正式发布的 `.dmg` 镜像，将 `OpenLXSSH.app` 拖入「应用程序」，然后从「应用程序」启动。若系统拦截启动，请先核对安装包来源与签名状态，不要关闭系统保护。
- **升级**：先结束进行中的 SFTP 传输并退出旧版 OpenLXSSH，再将新版 `OpenLXSSH.app` 拖入「应用程序」替换旧版。重启后不会自动恢复之前的 SSH 会话或终端标签。
- **本机数据与 Keychain v2**：
  - 主机与设置数据库位于当前用户的 `资源库/Application Support/OpenLXSSH/Data/OpenLXSSH.sqlite`。
  - 导入或生成的私钥副本存放在 App 专属受限目录中，不修改原始文件。
  - 选择「记住」的密码与私钥口令保存在现代本机 macOS 钥匙串（服务命名空间 `org.openlxssh.credentials.v2`，启用签名授权时使用本机 Data Protection Keychain，不通过 iCloud 同步；一次性验证码 OTP 从不保存）。从使用旧版钥匙串命名空间（v1）的版本升级时，旧条目不会静默迁移，首次连接按提示输入并勾选「记住」即可保存至 v2。
- **卸载**：如需清除已保存凭据与私钥，先在应用内的「密钥与凭据」中逐项忘记密码/口令、解除主机关联并删除不再使用的私钥副本，确认后退出应用并将 `OpenLXSSH.app` 移到废纸篓。移除应用本身不会自动删除 `Application Support/OpenLXSSH` 目录或本机钥匙串条目。

## 添加主机并连接

1. 在「保险箱」点击**新建主机**，填写名称、服务器地址、端口与用户名，选择认证方式。也支持将完整的 `ssh user@host -p 2222` 连接命令直接粘贴到地址或用户名栏，由界面识别后一键拆分填入（支持 JumpServer `#` 格式用户名）。
2. 使用 SSH 密钥时，先在「密钥与凭据」导入 OpenSSH 格式的 RSA 或 Ed25519 私钥副本，或直接生成 Ed25519 密钥并复制公钥到服务器。
3. 主机支持分组、标签与收藏管理；在主机编辑器的「高级 · 长连接保活」中可按需选择系统 TCP 保活预设（15 秒 / 30 秒 / 60 秒 / 关闭）。密码与私钥口令默认不保存，仅在明确勾选「记住」时写入本机钥匙串。
4. 双击主机打开 SSH 标签；如需对同一台主机建立多个独立会话，使用新建连接（`⌘T`）或终端分屏。
5. 首次连接时，请通过独立渠道核对界面展示的**完整 SHA-256 主机指纹**后再确认信任。若已知主机密钥发生变化，连接会被拒绝；请先独立核实原因，再前往「已知主机」处理。
6. 按服务器提示输入密码、私钥口令或 MFA 一次性验证码（或在手机端完成审批）。若本机钥匙串不可读或未授权，应用会回退为人工输入。

## 终端、分屏与多窗口

### 终端与嵌套 SSH

- 终端标签支持复制（`⌘C`）、粘贴（`⌘V`）、全选（`⌘A`）、页内查找（`⌘F`，`Enter`/`Shift-Enter` 跳转，`Esc` 关闭）与字号缩放（`⌘+` / `⌘-` / `⌘0`）。
- 滚动历史默认 10,000 行（上限 50,000 行），仅存于当前标签内存，断线后保留直至关闭标签，不落盘记录。可在「设置 → 终端」切换内置深色/浅色主题与字号。
- 多行粘贴会按原样发送，不自动补回车；即便远端开启 Bracketed Paste，也不能保证内容不会被执行。
- 登录跳板机后，可在远端终端中手动执行 `ssh 用户名@内网服务器`。内层连接的主机指纹校验与认证交互完全由远端终端处理，应用绝不会向内层提示自动投递本机凭据。

### 终端分屏

- **快捷键**：
  - `⌘D`：左右分屏（自动新建同主机 SSH 会话）
  - `⇧⌘D`：上下分屏（自动新建同主机 SSH 会话）
  - `⌥⌘]`：在两个分屏窗格之间切换输入焦点
  - `⇧⌥⌘D`：取消分屏（两个会话继续作为独立标签保留）
- **标签右键与分屏顶栏**：在标签栏右键某个会话标签，可选择「左右分屏显示」「上下分屏显示」或「取消分屏」；分屏窗格顶栏提供切换左右/上下方向、交换窗格位置、取消分屏与关闭单个窗格按钮。
- 分屏与单标签模式之间切换时，终端视图无缝重挂载，不会断开连接或丢失已有输出历史。

### 多窗口工作区

- 按 `⌘N`（或菜单「文件 → 新建窗口」）可打开多个独立工作区窗口。
- 每个窗口拥有独立的标签栏、终端会话/分屏布局与 SFTP 浏览上下文，同时共享同一份本机主机配置库、已知主机信任库与钥匙串。
- 常用工作区快捷键：`⌘1` 保险箱、`⌘2` SFTP、`⌘T` 新连接、`⌘⇧[` / `⌘⇧]` 切换前后标签、`⌘W` 关闭当前 SSH 标签（在固定管理页则关闭当前窗口）、`⌘,` 打开设置。

## 文件传输（SFTP）

1. 切换到 SFTP 页（`⌘2`），选择主机并点击**连接 SFTP**。若主机已记住密码或关联 SSH 密钥，应用默认沿用已保存的凭据；需要临时替换时，可切换为「仅本次输入」密码或私钥口令，服务器要求的 MFA / 交互式验证也会在连接时提示。
2. SFTP 与目标服务器独立建立直连，其当前目录与终端工作目录互不影响；经终端手动嵌套登录的内层主机仅限在终端中使用。
3. 连接后可在左右双栏浏览本地与远端目录，支持点击按钮、从 Finder 拖入上传或跨栏拖拽下载。传输文件夹时会安全校验并保留目录内的相对符号链接，阻止绝对路径、越界 `..` 与循环链接。
4. 遇到同名文件时，默认按「每次询问」弹出**取消 / 替换 / 都保留**选择（可在设置中调整默认冲突策略）；批量目录传输逐项报告成功、跳过或失败状态。
5. 底部全宽传输中心支持展开查看实时队列、单项详情、取消任务与重试失败项。切换标签或关闭 SSH 标签不会取消传输；关闭窗口或退出应用（`⌘Q`）时若有活跃传输，应用会提示选择继续保留窗口或取消传输并安全清理临时文件。

## 问题反馈

提交问题时，请附上 Mac 芯片型号、macOS 版本、OpenLXSSH 版本与构建号、复现步骤、预期行为与实际结果。请勿在日志或截图中包含密码、私钥、一次性验证码或真实敏感主机信息。
