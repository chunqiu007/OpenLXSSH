# OpenLXSSH 用户指南

OpenLXSSH 面向 Apple Silicon Mac，要求 macOS 26 或更新版本。1.0.0 build 3 已通过Apple公证，并完成票据、严格签名、Gatekeeper和本机安装启动验证；第二台Mac及部分实际人工场景仍待使用者验收。请使用随交付记录提供的最终ZIP，原内部候选仅作开发记录。

## 安装、升级与卸载

- **安装**：取得正式分发包，解压后将 OpenLXSSH.app 拖入“应用程序”，再从“应用程序”打开。若系统拒绝打开，请核对包的来源及发布状态，不要关闭系统保护或移除隔离属性。
- **升级**：先结束传输并退出旧版 OpenLXSSH，再用正式新版本替换“应用程序”中的旧 App。升级后检查主机配置和所需凭据是否可用；升级或重新安装后的凭据访问仍需实际验收。打开 App 不会自动恢复连接或终端标签。
- **卸载**：如需删除保存的秘密，先在 App 的“密钥与凭据”中逐个忘记主机密码和私钥口令、解除相关主机引用，并删除不再使用的凭据及 App 管理的私钥。共享项目可能仍被其他主机引用；按界面提示处理。清理失败时保留待清理记录并使用精确重试；仅丢弃恢复记录不会删除文件或钥匙串项目。确认后退出 App，将 OpenLXSSH.app 移到废纸篓。

移除 App 本身不会自动清除本机的 App 数据、管理的私钥副本或钥匙串记录。主机等 App 数据位于当前用户的“资源库/Application Support/OpenLXSSH”下；密码和已记住的私钥口令存于本机钥匙串，不同步。导入私钥时的原始文件不会随 App 副本删除。若清理失败，请在“密钥与凭据”查看提示并按精确记录重试，不要批量清除其他钥匙串项目。App 不提供私钥导出或备份功能，请自行保管原始密钥及必要备份。

## 添加主机并连接

1. 点击“添加主机”，填写名称、地址、端口和用户名，选择认证方式。使用私钥时，先在“密钥与凭据”导入 OpenSSH 格式的 RSA 或 Ed25519 私钥副本，或生成 Ed25519 密钥，再在主机配置中关联。可查看或复制公钥，服务器上的授权配置需自行完成。
2. 主机可放入单层文件夹或收藏；删除文件夹不会删除主机。复制主机保留共享凭据和密钥关联。密码或私钥口令默认不保存；只有明确选择“记住”才保存到本机钥匙串。保存主机配置本身不会发起连接。
3. 在主机列表双击主机打开 SSH；已有活动会话时会切换到该会话。需要多个独立会话时使用新建会话操作。
4. 首次连接时，通过服务器控制台或管理员等独立渠道核对界面上**完整的 SHA256 主机指纹**，一致后才确认并接受。若已知主机密钥变化，连接会被拒绝；先独立核实变化，再到可信主机管理中处理，不要盲目替换。
5. 按当前连接的提示人工输入密码、私钥口令或一次性验证码，或在手机上完成要求的审批。验证码不会保存；认证可以取消。已记住密码在部分系统或认证条件下仍可能要求手动输入。

## 终端和嵌套 SSH

终端标签可切换、复制、粘贴和搜索；断线后保留当前标签中的内存历史，可手动重连。关闭标签会结束该终端连接。退出或重新打开 App 后，需要自行重新连接。多行粘贴会直接发送；即使远端支持 Bracketed Paste，也不能保证粘贴内容不会被执行。

历史默认 10,000 行，上限 50,000 行；字体大小可设为 6–72。保存设置后应用到已有终端。默认配色跟随系统外观，选择预设或修改颜色后使用自定义配色。

登录跳板机后，可在远端终端中手动执行 `ssh 用户名@内网服务器`。内层密码、验证码和审批由用户在终端中处理；内层主机身份由跳板机上的 SSH 客户端核验。App 不自动管理跳板或使用本机保存的凭据回答内层提示。

## 文件传输

选择主机并打开“SFTP 文件”，按提示选择本次密码或私钥口令、连接并完成必要认证。SFTP 是独立直连，可能需要再次输入验证码；它不使用终端当前目录，也不能通过终端内层 SSH 访问文件。

连接后可浏览目录、上传文件或目录、下载所选项目，也可从 Finder 拖入上传。同名文件可按提示选择覆盖、跳过或单项改名，覆盖或跳过可用于同一主机的本批任务；额外风险需逐次核对。删除前核对界面列出的精确范围。符号链接默认不跟随。传输状态和取消入口在传输列表中；取消远端操作可能使共用该 SFTP 连接的其他任务失败。失败后可手动重试，重试从头创建新任务，不自动重连或续传。移除已完成记录不会删除文件或残留，先记下提示的精确残留路径。

文件传输逐项报告结果；覆盖整个文件夹不是一个整体事务。服务器能力不足、路径变化或取消可能导致部分项目失败或跳过，请检查每项结果和提示。

关闭 SSH 标签、切换标签或隐藏文件面板不会自动取消传输。关闭主窗口或退出 App 时，如有传输，按提示选择继续传输或取消传输并关闭；选择继续时保留窗口；选择取消并关闭后等待清理，若提示有无法清理的临时路径，请先记录并核对。

如果 App 提示数据位置或权限不合适，请核实 App 专属数据目录和所选导入文件的权限。App 会拒绝不安全的操作，不会自动清除权限设置。
