## 1. 产品与命名

- 正式产品名称：**OpenLXSSH**。项目、App 显示名称、Xcode Target、产品模块及文档使用此名称，辅助模块与测试可使用相应后缀。不擅自更名或更改工作目录。
- 原生 macOS SSH/SFTP 客户端；仅支持 Apple Silicon，最低 macOS 26。
- 两位个人用户各自独立使用；预计不超过 10 台主机，同时保持 1～5 个 SSH 会话。规模是设计负载，不应实现为人为的主机数量限制。
- 参考 Termius 的主机与凭据管理便捷性，以及 MobaXterm 的文件传输体验；不复刻完整产品，不整套重写其他语言的客户端。
- 不依赖 Electron、JVM、云端账号或在线服务来运行核心功能。签名公证、下载开发依赖及用户主动在远端使用联网程序不属于 App 云端依赖。
- 优先顺序：认证正确与秘密保护、终端兼容性、文件完整性、长期稳定与资源释放、操作便捷，再优化绝对内存数字。

## 2. 主机管理（HOST）

- HOST-01：手动添加、编辑、复制、删除主机；配置名称、地址、端口、用户名和认证关联。
- HOST-02：单层文件夹、收藏、搜索；收藏是既有主机的入口，不复制认证配置。
- HOST-03：双击发起 SSH；已有活动会话时切换至已有标签。多会话时选择最近活动的有效会话，并保持行为一致。
- HOST-04：通过显式操作，为同一主机创建额外独立会话。
- HOST-05：不要求导入 `~/.ssh/config`。App 维护自己的配置、数据和可信主机记录，不修改用户系统 SSH 配置。
- HOST-06：保存最近连接时间；删除主机不应误删仍被其他主机使用的凭据或私钥。

## 3. 凭据与认证（AUTH / KEY）

V1.0 必须覆盖直接 SSH 连接的四类流程：

| 编号 | 流程 | 交互要求 |
| --- | --- | --- |
| AUTH-01 | SSH 私钥 | 使用关联的 Ed25519/RSA 私钥；正确处理有口令和无口令文件 |
| AUTH-02 | 用户名＋密码 | 已获授权保存时尝试自动使用长期凭据；未保存时人工输入 |
| AUTH-03 | SSH 私钥＋手机动态验证码 | 私钥认证后由用户输入验证码 |
| AUTH-04 | 用户名＋密码＋手机动态验证码 | 长期密码与一次性挑战分开处理 |

- AUTH-05：支持多轮 Keyboard-Interactive；对手机审批流程正确显示必要信息并等待、允许取消，不伪造或绕过审批。
- AUTH-06：允许添加主机时选择是否记住密码，不默认保存用户没有授权保存的秘密。已保存凭据在 Mac 已解锁、公司策略允许时尽量自动使用；不强制每次 Touch ID。
- AUTH-07：密码、私钥解锁口令存于 Keychain，禁用同步；OTP 不保存、不写日志。不能可靠判别的认证挑战交由用户输入，不能猜测并发送已保存密码。
- AUTH-08：禁止扫描普通终端输出、匹配 `Password:` 等文字后自动发送秘密。认证输入与已启动的直接连接及用户授权绑定，防止并发会话串用凭据。
- AUTH-09：认证失败、重试、取消、超时、Keychain 不可用和关闭标签均有明确状态；不能无限自动重试触发账户锁定。
- KEY-01：App 集中管理私钥；支持导入 Ed25519/RSA 私钥，并生成新的 Ed25519 密钥。使用标准 OpenSSH 格式和成熟工具，不自创格式或密码学。
- KEY-02：私钥保存在 App 专属目录并设置适当权限；导入采用明确的 App 管理副本，不改写或删除原始文件。正确处理共享引用和删除。
- KEY-03：支持显示/复制公钥以便用户配置服务器授权；这不等于导出私钥或开发备份功能。不自动修改生产服务器 `authorized_keys`。

## 4. 手动嵌套 SSH（NEST）

- NEST-01：用户先使用 App 登录公司跳板机；进入远程终端后自行执行 `ssh 用户名@内网服务器`，第二跳的密码、验证码、审批均由用户在终端内手动完成。
- NEST-02：App 只管理最外层直接连接。不得识别内层提示并注入本机 Keychain 凭据、拦截内部认证或擅自发起额外连接。
- NEST-03：保证交互输入、控制键、终端大小变化及嵌套 SSH 退出后返回上一层终端正常。不承诺 App 能识别或管理每一层远端会话。
- NEST-04：嵌套 SSH 的目标主机身份由跳板机上的 SSH 客户端和其配置处理；App 的可信主机列表只覆盖自身直接建立的 SSH/SFTP 连接。
- 不实现自动 ProxyJump、多级跳板管理、经跳板机的图形化 SFTP。本地/远程端口转发延期，不作为 V1.0 的隐藏任务、配置必填项或完成门槛。

## 5. 终端（TERM）

- TERM-01：多个独立 SSH 标签，无终端分屏。切换标签不重建连接。
- TERM-02：默认历史 10,000 行，可配置且有合理上限；断线后保留当前标签内仍可用的输出，提供手动重连，不自动重连。
- TERM-03：复制、粘贴、历史搜索；多行直接粘贴，不额外确认。正确处理 Bracketed Paste，不能据此保证远端程序不执行所粘贴内容。
- TERM-04：支持系统深浅色、自定义字体、字号与配色；正确显示中文、Unicode、Emoji，验证中文输入法与组合字符。
- TERM-05：验证 Ctrl+C、方向键、Tab、窗口缩放以及 Vim/Neovim、tmux、htop/btop、Docker 日志、Claude Code/OpenCode 等交互程序。
- TERM-06：默认启用适度 SSH 保活，允许按主机调整；保活不等于自动重连，也不能保证远端任务断线后继续运行。
- TERM-07：关闭标签直接取消连接/认证并结束最外层会话，释放本机资源，不弹普通确认；远端任务是否继续由远端程序决定。

## 6. SFTP 与传输（FILE）

- FILE-01：右侧单栏远程文件浏览器，默认隐藏，用户打开时才按需连接与认证；仅覆盖 App 能直接建立 SFTP 连接的服务器。
- FILE-02：支持直接服务器上的密码、私钥及适用的交互认证；与 SSH 可以分别认证、重复输入 MFA，不要求共享连接或复用认证会话。
- FILE-03：浏览目录；上传/下载单个文件、多文件及整个文件夹；支持 Finder 拖入上传。
- FILE-04：创建目录、重命名、删除文件与目录；明确删除目标与递归范围，危险删除需要产品内确认。原规范某阶段出现的“文件创建”不扩张成空文件编辑器。
- FILE-05：传输队列、进度、取消、失败原因；同名文件选择覆盖、跳过、重命名，并可应用到本次批量任务。
- FILE-06：采用流式传输和有界并发；取消或失败不得静默损坏原有目标文件。临时文件唯一、可追踪，完成后按服务器能力安全提交；不能保证安全覆盖时明确提示。
- FILE-07：文件夹递归包含中文、空格和特殊文件名；符号链接必须有明确策略，防止循环、越界或误删除。策略由技术验证形成 ADR，不默默跳过后宣称整个文件夹成功。
- FILE-08：SFTP 传输不依赖终端标签存活；关闭标签、切换标签或隐藏文件面板不取消传输。任务仍有可见入口。
- FILE-09（2026-11-04用户明确更新）：用户仍持有的SFTP会话不因60秒无传输、切页、阅读列表或观察者退出而主动释放；独立用户会话租约与活动任务／操作租约分开。显式断开、换主机、关闭窗口或退出释放该用户归属，活动任务仍保持至真实结束；无人持有的后台连接按需回收。轻量协议健康检查串行执行，真实失败准确显示，不自动认证或重传。普通上传在实际目标范围内自动核验安全提交能力，不要求手工工程检查；无安全能力则准确失败并保护原文件。

## 7. 窗口与生命周期（LIFE）

| 操作 | 必须行为 |
| --- | --- |
| 关闭 SSH 标签 | 不确认，取消/断开该终端会话，SFTP 传输继续 |
| 隐藏 App、最小化窗口、切换标签 | 保持连接与传输，减少不必要重绘 |
| 关闭主窗口，无传输 | 断开全部 SSH/SFTP、释放终端和文件连接；App 可以留在 Dock |
| 关闭主窗口，有传输 | 拦截关闭，提供“继续传输”或“取消传输并关闭”；继续传输意味着保留窗口 |
| 退出 App，有传输 | 拦截退出，待用户选择后执行；取消时清理可安全清理的临时产物 |
| 重新打开窗口或启动 App | 只显示主机列表，不恢复连接、标签或持久化终端输出，不触发 MFA |

## 8. 安全、性能与交付（SEC / PERF / DIST）

- SEC-01：App 直接连接的服务器首次需明确主机密钥信任判断；已知密钥变化时阻止连接，提供经人工核实后的管理路径，不静默删除或替换信任记录。
- SEC-02：不把秘密写入日志、启动参数、普通配置、数据库或测试产物；不向 AI 提供真实公司凭据；测试使用一次性密钥与隔离服务。
- SEC-03：受控进程参数和 SSH 配置，不执行由主机字段拼接出的任意 Shell 指令；默认禁止 Agent Forwarding 和不必要连接复用。
- SEC-04：依赖固定版本/提交，记录来源、许可证及传递依赖。Sandbox 通过兼容性与安全评估决定，不关闭 Gatekeeper、SIP 或其他系统保护。
- PERF-01：空闲界面争取低于 200 MB，5 个普通会话争取低于 500 MB；均计入 App 拥有的子进程。属于优化目标，超出时实测分析并报告，不能掩盖数据，也不以此要求无限重写。
- PERF-02：历史、输入输出队列、传输缓冲均有界；关闭会话清理进程、PTY、描述符和异步任务，无持续无界内存增长。
- PERF-03：执行200次连接关闭、五会话长时间稳定运行、输出压力、标签切换、文件传输及网络异常测试。2026-10-29用户明确接受本轮约9小时38分钟（awake/continuous34694.635秒）的五真实会话稳定记录，取消必须满24小时的交付条件，不再为此重跑。原24h任务中断、缺少正常end/cleanup及原失败记录仍保留，不表述为完成24小时或拼接时长。
- DIST-01：Release 产物为 Apple Silicon / macOS 26 的 `.app`，可附 `.dmg`；两台 Mac 安装与实际使用验收，附安装使用说明。
- DIST-02：用户已有开发者账号，可采用 Developer ID 签名、公证；具体证书可用性、系统授权和上传条件须实际核实。不把持有账号等同于签名已完成。
- DIST-03：不开发自动更新；不通过修改系统保护或静默移除隔离标记来解决安装问题。
