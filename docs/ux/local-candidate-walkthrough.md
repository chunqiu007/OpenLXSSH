# 新桌面体验：候选操作路径与待验清单

状态：**验收路径已整理；正常Debug工程实物已独立构建/签名，但正常启动和GUI未验，尚未交付体验候选，未达到 UX_READY_FOR_USER。** 2026-11-01。新实物身份与禁止混用的边界见 `normal-engineering-preview-review.md`。

本页面向当前 Termius 桌面体验重构，不替代 `docs/user-guide.md` 中已经公证的旧 build3 使用说明。当前 `AppTrust-M3-Live-R1/OpenLXSSH.app` 是 HostProbe：**只有经已审 wrapper、精确 fixture flags 与契约启动的验证模式才使用隔离输入并自动退出**，它并非默认隔离或默认自退。无参数启动可能访问既有 App 数据位置，禁止双击它作日常体验或空白测试环境，也不要安装覆盖旧版。新版正常候选将有独立身份单；不存在身份单与正常启动证据时，不宣称已交付。

## 候选身份必须包含什么

实际体验记录须对应同一份 App 的准确路径、main/helper SHA、源码输入摘要（不只 Git HEAD）、arm64/minOS26、签名/许可及当前默认后端。截图绑定该候选与相应状态。离线签名不等于 Apple 公证；当前没有新的 Apple 上传、时间戳或最终发行包。

当前普通连接仍用 Direct，编辑器确有本次密码时的显式 prepared handoff 使用 Native 候选。两个入口尚未统一，不能用 HostProbe 注入 Native 后的真实认证成功，冒普通列表双击也已通过。此缺口见 `../adr/ux-native-ssh-entry-consistency.md`。

## 安全的体验前置

- 仅使用虚构条目和已明确批准的隔离测试服务。不要把公司地址、密码、私钥、OTP、完整终端内容发入问题报告或截图。
- 不清空旧数据库、不修改系统 SSH 配置、不批量清钥匙串、不移除系统保护来解决启动问题。未明确指定隔离数据位置的普通 App 使用现有本地数据，不把它当空白测试环境。
- 主机指纹从独立可信渠道核对完整 SHA256；变化时拒绝连接，不以删除记录或“忽略”代替核实。
- 不启用自动重连/会话恢复、自动 ProxyJump、端口转发或内层 SSH/sudo 凭据投递。

## 正常候选的逐步路径

以下是验收目标，不表示每一步已通过 GUI。按顺序记录“通过/失败/未测”和实际构建身份；取消/失败也需检查可恢复状态。

### 1. 工作区与主机

启动应显示固定保险箱与 SFTP 页，不恢复旧 SSH 会话、终端内容或认证答案。切固定页不取消连接或传输。创建主机前后分别检查空列表、无选择、列表/卡片、长名称/地址及窄窗口；搜索名称、地址、用户、组路径和标签，清除筛选后原数据仍在。

在虚构组织中测试新建/重命名/移动/复制/删除分组与标签，核精确影响范围；删除分组不删除主机，解除标签关联不删除全局标签实体。多选不能隐式连接全部主机。

### 2. 编辑与秘密

创建或编辑主机，核两种主认证选择及相关字段。测试无效端口/地址、有效保存、保存中重复点击、失败重试，以及 Save/Discard/Cancel：取消保留草稿，放弃清除本次输入，保存失败不假装关闭。

密码默认掩码，显式显示后失焦/关闭恢复；未记住的本次密码只用于此次连接。保存密码的授权与“本次使用”分开。已保存的秘密不为打开编辑器而读出填回普通文本。保存并连接须在保存提交和准确 dismiss 后只发起一次连接，不能双击产生两个 owner。

### 3. 密钥与已知主机

只导入明确的测试私钥管理副本；取消不改变原件。重复公钥应明确选择复用/取消，而非因文件名不同新增一份。标签、指纹和引用数是公开元数据；复制公钥与导出私钥不同，本项目不提供私钥导出或自动写服务器授权。

测试已知主机搜索、复制完整公开指纹及精确移除；移除只影响所选 App 记录，不改系统 known_hosts。已有引用的密钥/凭据删除必须说明影响，不误删共享秘密。

### 4. 连接、首次信任与并发挑战

分别覆盖首次“关闭”“仅此次继续”“添加并继续”；仅此次后的新连接仍需确认，持久后的准确同 key 不重复询问。变化为独立拒绝状态，无普通继续。

分别以密码和密钥主方式连接需要附加挑战的隔离服务，核多轮、多字段、echo、零输入通知和取消。两会话同时等待时，切换/取消 A 不改变 B 的输入或 owner；旧回答不得进入 B 或新代次。不得按终端文字自动投长期秘密。

当前信任实网三分项已成立，但三案仍 weak cleanup 失败；单 MFA 分项也不等并发取消与整体资源通过。见 `app-trust-real-review.md`、`app-mfa-real-review.md`。

### 5. 终端与会话标签

双击主机应定位最近有效活动会话，显式新会话才另建。修改连接参数后使用新快照，纯名称/收藏/分组不重连。切标签保留同一真实终端与历史、搜索、选择及滚动。

核近黑底浅字、ANSI 颜色、宽字符、组合字符、复制选区、两次真实 Cmd+V、Ctrl+C 与 Cmd+C 的区别、Bracketed Paste、搜索/上下一个/无结果/Escape归还焦点、字号及还原。多行粘贴不会自动补回车，也不能承诺远端不会执行。

中文输入法组合、候选窗位置、实体符号键和不同键盘布局需要实际输入验证；模型/几何测试不代验。短 Vim/tmux/htop 验证包含尺寸变化和 alternate-screen 返回。标签中键、关闭其他/右侧、活动标签关闭后的邻项及最后回保险箱分别记录；当前中键原生事件门仍未通过。

### 6. 双栏 SFTP 与传输

未连接远端时左本地仍可用；远端从共用主机目录选择，不跟随终端 cd 或内层 SSH。两侧分别测试路径编辑、Enter/Escape、后退/前进/上级/刷新、过滤、隐藏项、多选、列宽/列序/水平滚动及失败保留最后成功位置。

先用小的中文/空格/隐藏/组合文件名目录，明确本地与远端目标，审核递归清单；确认前不创建任务或开始内容传输。核 Finder 拖入/跨栏拖放的锁定目标，不能在切路径后误投。删除先看精确范围，不跟随符号链接越界。

冲突分别检查改名、跳过、覆盖及本批范围；额外风险不得被批策略自动接受。目录逐项结果可能部分成功，不能称整体事务或 CAS。取消不回删已完成文件；重新传输需新审核/确认和新任务，从零开始，不冒断点续传。清已完成记录不删文件、不取消活动任务；切页/关 SSH 后队列继续并有入口。

真实小清单往返、rename+skip、受控在途取消后新清单重试已过严格资源门；它们不代 Finder/拖放/完整队列 GUI，也不证明 native 阻塞 I/O 中断或所有批传播。见三份 `app-files-*-real-review.md`。

### 7. 设置、窗口与退出

从菜单与 Cmd+, 打开同一六分类设置，核真实等宽字体、默认深色预览、光标、保存/失败、类别/全部重置。重置只改草稿，保存后生效，不清主机/密钥/凭据。帮助/许可离线可读，诊断先预览再显式复制，不自动上传。

在底层主机脏草稿加设置 overlay 时，逐层测试 Cmd+W、红点与 Cmd+Q 的 Save/Discard/Cancel。存在传输时继续应保留窗口，取消并关闭应等待真实清理；不能因窗口消失推断资源释放。重新打开不自动建立连接。

### 8. 视觉与布局记录

用同一正常候选，逐一记录 **1000×650、1280×800、1440×900逻辑尺寸及全屏**；920×580作为额外最窄边界，不替代规定的三档。覆盖 Vault/编辑/Keys/信任/认证、SFTP未连与已连、任务及设置，再做连续缩放和长内容滚动。核文字裁切、底部按钮、禁用/悬停/焦点、标签溢出与双栏拖动。

当前图像观察能力不支持新版像素输入，官方 CUA 也未形成可用的真实前台观察证据。截图文件存在、AX 树、`NSWindow.isVisible` 或编译成功均不能代像素和实体交互通过。现不猜坐标、不强激活或关闭可见性暂停绕门。

## 问题记录的最小字段

候选身份、页面/动作、前置状态、实际结果、期望结果、是否可重复，以及脱敏截图（若有）。资源问题附非秘密 run ID 和对应公开收据，不提供密码、OTP、私钥内容/摘要、完整会话或用户目录清单。未测就记未测，不把未测计入通过率。
