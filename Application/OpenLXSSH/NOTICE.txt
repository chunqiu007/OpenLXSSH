OpenLXSSH includes OpenLXSSHCore and GRDB.swift 7.11.1, revision b83108d10f42680d78f23fe4d4d80fc88dab3212.
Source: https://github.com/groue/GRDB.swift
License: MIT; see GRDB-LICENSE.txt in this bundle.
SQLite is supplied by macOS, not by a developer-machine runtime library.
OpenLXSSHSecurity is a local first-party package using system Security.framework and /usr/bin/ssh-keygen.
The App explicitly uses local file-based Keychain with system creator ACL, no cloud synchronization.
Screen lock does not imply Keychain lock. No private key export or backup is provided.
OpenLXSSHTransport uses system OpenSSH and SwiftTerm 1.99.1 (2f573f73af5e768d90847dce20c97fa9535d7164 preview).
SwiftTerm source: https://github.com/migueldeicaza/SwiftTerm.git; MIT, see SwiftTerm-LICENSE.
Transitive pinned build dependencies: swift-argument-parser 1.8.2 (Apache-2.0), swift-png 4.5.2 and h 1.0.1.
See bundled ArgumentParser-LICENSE, SwiftPNG-LICENSE/NOTICE and H-LICENSE/NOTICE for their terms.
OpenLXSSHTrust is the sole App-owned known_hosts store shared by direct transports.
OpenLXSSHFiles statically links libssh2 1.11.1 and OpenSSL 3.5.9 LTS (not FIPS certified).
Sources: https://www.libssh2.org and https://openssl-library.org; pinned provenance and native hashes are in FilesNativeLicenses/manifest.json.
